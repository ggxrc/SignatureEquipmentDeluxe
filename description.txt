Progression é um mod inspirado no mod SignatureEquipment, que adiciona um 
sistema de progressão para equipamento no Terraria. Quer jogar com qualquer arma? Com esse mod é possível!

as seguintes funcionalidades são:
- Adição de níveis para armas e armaduras.
- Melhoria de atributos conforme o nível do equipamento aumenta.
- Sistema de experiência para equipamentos.
- Tipos diferentes de progressão.
- Compatibilidade com mods populares de Terraria (Em progresso).
- Inimigos com nivelamento dinâmico baseado no nível do mundo (Em progresso).
- sistema de killstreaks para aumentar a experiência ganha (Em progresso).
- sistema de eventos que afetam o ganho de experiência (Em progresso).
- outras coisas que serão adicionadas futuramente!

ENGLISH VERSION

Progression is a mod inspired by SignatureEquipment, which adds an equipment progression system to Terraria. Want to play with any weapon? With this mod it's possible!

Features:
- Level system for weapons and armors.
- Attribute improvements as equipment level increases.
- Experience system for equipment.
- Different progression types.
- Compatibility with popular Terraria mods (In progress).
- Enemies with dynamic leveling based on world level (In progress).
- Killstreak system to increase experience gained (In progress).
- Event system affecting experience gain (In progress).
- More features to be added in the future!

Planned Version Roadmap:

v0.1.x (Current Version):
- Initial AI-assisted version to demonstrate the mod concept. Expect to find quite a few bugs.

v0.2.x:
- All configurations working as intended.
- Removed redundant configs created by AI.
- English and Portuguese localization.

v0.3.x:
- Restructured attribute scaling (damage, mana cost, etc.).
- New default configuration for a satisfying experience.

v0.4.x:
- Compatibility with Terraria Overhaul mechanics.
- New class-based progression mode (future compatibility with class mods).
- Full Multiplayer compatibility (may work now, but nothing has been tested).

v0.5.x:
- Compatibility with Orchid Mod classes.
- Compatibility with Demolisher Mod.

v0.6.x:
- Event system upgrade.
- UI polish.

v0.7.x:
- Scaling for damage-dealing debuffs (e.g., Poison, Burning, etc.).
- Compatibility with The Stars Above Mod.

v0.8.x:
- New weapon buff options.
- Compatibility with Thorium Mod.

v0.9.x:
- Revamped armor progression system.
- New buff system for armors.
- UI polish.

v1.0.x:
- First stable version of the mod.
- Addition of Juice Effects, particles and sounds to improve experience.
- Performance optimizations.
- Other improvements and bug fixes.
- Compatibility with Starlight River and Calamity.
- Creation of 80x80 and 30x30 icons for mod cover.


This is my first mod, so please leave feedback so the mod can improve, and I can learn more about Terraria modding!
